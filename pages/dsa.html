1. Official Exam Pattern & Marking Scheme

• DSSSB TGT Computer Science (Source, Syllabus): 200 Questions, 200 Marks, 120 Minutes (Single-Tier CBT). Section A (100 Qs: General Awareness, Reasoning, Arithmetical/Numerical Ability, Hindi, English) + Section B (100 Qs: Core Computer Science).

• Negative Marking: +1.0 mark per correct answer and -0.25 mark (1/4th) deducted per wrong answer. (Configurable in our Mock Test Engine for KVS/NVS zero-negative patterns).

• Identified Official DSSSB TGT CS Shifts (Adda247): 12 Sept 2025 (Shift 1), 07 Feb 2024 (Shift 2), 24 June 2023 (Shifts 2 & 3), 25 June 2023 (Shift 2), 01 Aug 2021 (Shifts 2 & 3), 07 Aug 2021 (Shifts 1, 2 & 3), and 21 May 2017.

2. High-Yield DSA Topics in Actual Papers

• 2025 DSSSB TGT CS (12 Sept 2025 Shift 1): Emphasized Linked List node structure (PYQ), SLL traversal disadvantages (PYQ), Merge Sort as optimal linked-list sort (PYQ), dynamic array beginning-deletion O(n) (PYQ), and C Call-by-Address pointers (PYQ).

• 2021 DSSSB TGT CS Shifts: Tested Post-order traversal Left, Right, Node (7 Aug S1), Sparse vs Dense Matrices (7 Aug S1), Max-Heap swap counting (7 Aug S2), Full Binary Tree definition (1 Aug S2), and average-case complexity ordering (1 Aug S3).

3. KVS / NVS / PGT Benchmark Synthesis & QA

• KVS PGT CS (2018 & 23 Feb 2023 Shift 2): Focused on Stack TOP pointer (2023 PYQ), BST worst-case O(n) search (2018 PYQ), BST subtree counts (2018 PYQ), Strictly vs Complete Binary Trees (2018 PYQ), and recursive sorting (2018 PYQ).

• Simulator & Execution Transparency: All algorithm visualisers and tracing tools execute deterministically in browser JavaScript in real time without requiring an external C++ compiler or internet connection; C++17 code and C-style pseudocode are displayed alongside live interactive JS state engines.
